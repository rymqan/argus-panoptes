# Argus Panoptes

Стоглазый страж кинорасписаний Астаны. Следит за сеансами и присылает в Telegram картинку зала
с лучшей свободной парой мест по центру.

## Что делает

`seats.py` обходит четыре кинотеатра на левом берегу — Kinopark 7 Keruen, Kinopark 8 Saryarka,
Chaplin MEGA Silk Way и Chaplin Khan Shatyr — и для каждого подходящего сеанса:

1. вытягивает настоящую схему зала с занятостью;
2. выбрасывает первые и последние ряды и крайние кресла;
3. ищет пары соседних свободных мест и ранжирует по близости к центру зала;
4. рисует схему в PNG и шлёт её через `sendPhoto`.

Правила времени: в будни только вечер (с 18:00), в выходные всё кроме утра (с 12:00), начало не позже 22:30.

## Две системы бронирования

| Сеть | Расписание | Схема зала |
|---|---|---|
| Kinopark | `afisha.api.kinopark.kz` | `booking.api.kinopark.kz` |
| Chaplin | `chaplin.kz/api/get-cinema-schedule` | `chaplin.kz/api/get-hall` |

Токены Kinopark читаются из публичного runtime-конфига их сайта при каждом запуске, поэтому
ротация ключей ничего не ломает. Их WAF отвечает 425 без заголовков `Origin`/`Referer`.

Осторожно: в расписании Kinopark **название зала не соответствует реальному** — под одной меткой
в разные часы идут разные залы. Настоящий зал берётся только из ответа booking API.

## Настройки

- Переменные репозитория: `MOVIE` (по умолчанию «Человек-паук»), `DAYS` (7)
- Секреты: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`
- `seats_state.json` — дедуп уже отправленных вариантов, коммитится воркфлоу

Ручной запуск: `gh workflow run seats.yml -f force=true`
