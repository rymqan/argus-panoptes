# Lessons

## Не выдавать геометрию зала за размер экрана (повторилось дважды)
- Ошибка: ранжировал залы по числу мест / ширине рядов, будто это размер экрана. Пользователь ловил это дважды (Spider-Man: Kinopark 7 Зал 5; Dune: Kinopark 8 IMAX).
- Факт: в Kinopark booking API `grid.x` — индекс сетки, не метры. Ширина ряда ничего не говорит о ширине экрана.
- Правило: «лучший зал» объявлять только по опубликованному размеру экрана / формату. Нет данных — ставить залы на один уровень и прямо говорить, чего не знаю.
